# Codebook

This folder will hold:

- `codebook.md`: definitions for every coded variable (loot box presence, disclosure completeness, presentation features, dark-pattern types, Public Disclosure Index 0–10).
- `keyword_dictionary.csv`: odds-related terms in English, Korean, Dutch, French, and German.
- `rule_revisions.md`: a dated log of every change to the coding rules and why it was made.
- `validation_report.md`: precision, recall, and Krippendorff's alpha for the hand-coded 20% sample.

Unclear cases are coded as `unknown`, never guessed.
